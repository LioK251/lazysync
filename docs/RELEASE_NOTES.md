lazysync 0.2.0 introduces a simpler dark gray-and-white interface.

- A left-expanding Difference checker compares local files with the fetched GitHub branch, including unpushed commits.
- Side-by-side previews include syntax highlighting, aligned line numbers, changed-line markers, and binary/deletion indicators.
- Choose ignored files, folders, and patterns during private repository creation or in repository settings. Existing .gitignore rules are preserved.
- Drag the top bar to move the app. Switching to another app keeps lazysync visible.
- The bottom Quit button is removed; Quit remains available in the tray menu.

Download the Windows x64 `.exe` installer (or `.msi`), or the `.dmg` for your Mac: `aarch64` for Apple Silicon and `x64` for Intel. Git must be installed and available on PATH.

Installers built without signing secrets are unsigned and may prompt operating system trust warnings. This release does not include automatic updates.
